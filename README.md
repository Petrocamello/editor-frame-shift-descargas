# Editor FRAME // SHIFT · descargas

Instaladores del **Editor FRAME // SHIFT**, el editor de video de la academia [FRAME // SHIFT](https://academia.frameshiftpro.com) para sus alumnos. Gratis.

Aquí solo están los instaladores (el código no es público).

## Descargar

Entra a **[la última versión](../../releases/latest)** y baja el archivo de tu computadora:

| Computadora | Archivo |
| --- | --- |
| Windows 10 / 11 (64 bits) | `Editor-FRAME-SHIFT-<versión>-windows.exe` |
| Mac con Apple Silicon (M1, M2, M3…) | `Editor-FRAME-SHIFT-<versión>-mac-arm64.dmg` |
| Mac con Intel | `Editor-FRAME-SHIFT-<versión>-mac-x86_64.dmg` |

- **Windows:** abre el instalador. Si Windows dice «Windows protegió tu PC», toca «Más información» › «Ejecutar de todas formas» (el programa no está firmado todavía).
- **Mac:** abre el .dmg y arrastra la app a Aplicaciones. La primera vez, clic derecho en la app › «Abrir» › «Abrir igualmente» (no está firmada por Apple todavía).

## Actualizaciones

El programa avisa solo cuando hay una versión nueva: aparece el botón **«Actualizar»** con la lista de novedades.
